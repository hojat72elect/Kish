## Roadmap for Kish programming language

At this point, my general idea of this programming language is that I don't want to replace C++.
Instead, I want to make it easier to take advantage of C++ everywhere. Meaning is that I want the Kish programming language to **make it very easy, safe, and efficient to write wrapper around C++ code**.

I want a language that takes all the good parts of <u>Python</u>, <u>Kotlin</u>, and <u>JavaScript</u>.<br/>
It should be **self-sufficient**, **batteries-included** and **easy to use for network programming**
just like Python.

I also want it to have **curly braces** so it doesn't make me mad with indentation. Other than that, the most important feature of the JS that I want in Kish programming language is **cross-platform** and **easy UI development**.
This langauge should have an internal library that allows for mutiplatform UI development. this language should be able to develop UI for dektop, web, and mobile (so in fact, we'll have a mixture of tkinter, React Native, React, Compose Multiplatform, and Electron JS, all in one programming language).

Another point, I want to make this language a very good choice for academia, which means it should have a **very easy to understand syntax**. I'm gonna get the good parts of kotlin and python for this matter.
Since it's gonna be appealing to academic folks, I want it to have an **interactive notebook mode**(just like jupyter notebooks), and also support **Complex numbers** as well as **Symbolic mathematics**.

this langauge should allow you to think and express yourself in the most human way possible. Which means I will borrow notions such as **interface**, **extension functions**, **first class citizen functions**, **Sealed classes**, **annotations**, **abstract classes**, and **single-parent inheritence** from <u>Kotlin</u> programming langauge.

It's very important to make this language more resilient and easier to work with compared to JS and Python. And also **it should be faster** than those 2.
This whole langauge **should be written in fast and portable C++**. It should have a **pretty decent VM and GC** something like the occurrence counting GC that the swift lang has. I understand that this will be a breaking change from python and JS, but I want this lang to as strongly typed as fuck.

No general-purpose programming language in this world will survive if it doesn't support and data-engineering at least to some point. Kish language should support **No SQL** databases through json, xml, and MongoDB. it should also be versed in **SQL** databases such as sqlite, MySQL, MariaDB, and PostGreSQL.

the source code written in Kish should transpile to JavaScript, work with web assembly, and natively run on iOS and Android.
